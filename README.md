# Hi, I'm Arthur Arnst

I like building software close to the system: backend services, networking
tools, developer utilities, and language tooling.

I work mostly with Rust and Python. Depending on the project, that also means
databases, async APIs, WebSockets, Linux servers, Docker, or a small desktop
client that makes the whole thing useful.

## What I work with

- Rust and Python
- Async services, APIs, WebSockets, and network protocols
- PostgreSQL, MySQL, Redis, Kafka, and MinIO/S3
- Linux, Docker, Caddy, and VPS deployments
- TypeScript, React, SolidJS, and Tauri for product clients

I use Claude and ChatGPT as development tools for research, prototyping,
boilerplate, and test ideas. I still own the architecture, security decisions,
code review, and final implementation.

## Selected work

- [macmgr](https://github.com/nimeview/macmgr) — Rust TUI/CLI for macOS services,
  packages, configuration, themes, snapshots, and diagnostics.
- [Flux](https://github.com/nimeview/Flux) — experimental reactive programming
  language and compiler toolchain in Rust with a VM, JIT, formatter, CLI, and LSP.
- [nimesvc](https://github.com/nimeview/nimesvc) — Rust DSL and CLI for generating
  typed HTTP, gRPC, WebSocket, and event-driven services in Rust, TypeScript, and Go.
- [MRLess](https://github.com/nimeview/MRLess) — local mesh messenger with a
  SolidJS client and a Rust peer node for discovery, relay routing, and storage.
- [NimeNetwork](https://github.com/nimeview/NimeNetwork) — private Rust platform
  for mesh networking, internal DNS, service discovery, and operations.

Most of these repositories are private while I finish the documentation and
release presentation. MindPro and FileFlow are private projects and are not
intended to expose their source code.
